Astrology Conjunction Finder — AWS Architecture

One CloudFront distribution, two origins, no database — as actually deployed to conjunctionfinder.ca

Frontend delivery

  • • One CloudFront distribution, two cache behaviors: /* → S3, /api/* → API Gateway
  • • S3 bucket is fully private — reached only via Origin Access Control, no public bucket policy
  • • conjunctionfinder.ca + www, backed by an ACM cert in us-east-1 (CloudFront's hard requirement)
  • • The default *.cloudfront.net name keeps working alongside the custom domain, never disabled

Backend & compute

  • • API Gateway HTTP API → Lambda container image (FastAPI + Mangum, pyswisseph + Swiss Ephemeris files)
  • • /api/* forwarded with the ALL_VIEWER_EXCEPT_HOST_HEADER policy — CloudFront's Host header would otherwise break API Gateway's regional endpoint
  • • No database, no persistence — every request carries its own birth data and gets answered in one round trip
  • • Only real outbound dependency: Nominatim for geocoding a birth place name

Observability & security

  • • Structured JSON logs: Lambda app logs + API Gateway access logs, both in CloudWatch Logs
  • • S3 + CloudFront access logs land in one shared, private logging bucket
  • • CloudWatch RUM (errors, performance, http) fed directly from the browser via a Cognito unauthenticated identity pool — bypasses CloudFront entirely, scoped to rum:PutRumEvents only
  • • Measured cost at 1,000 API hits + <100 page loads/month: ≈$0.55, almost entirely the $0.50 Route 53 hosted zone fee
